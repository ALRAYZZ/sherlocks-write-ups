# Sherlocks Write-ups

This repo contains my write-ups for different cybersecurity labs and Sherlocks I've worked through.

Most of these are notes I originally took for myself while solving the exercises, so the write-ups follow my own process and show how I approached each task rather than being a perfect step-by-step guide.

The main topics covered are things like:

- Digital Forensics
- Memory Analysis
- Volatility
- Windows Event Logs
- Sysmon
- PowerShell
- Malware Analysis
- Threat Hunting
- OSINT

I'm keeping the write-ups here as a reference for myself and hopefully they can also be useful to someone else going through the same exercises.
